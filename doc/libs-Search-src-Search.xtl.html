librarylibs/Search/src/Search.xtl

Search: searching and ranking -- positions in sorted lists, merges, the k largest, ranks with ties, nearest items, order statistics, ranges. Import it with an alias of your choice: "sr:" u_se< "Search". Put libs/Search/src on XETAL_PATH ("just path"); the reference is libs/Search/docs. Names with l: are exported; those under h: are private to this file.

Positions count from 1, as everywhere in X_eTaL. Binary search is Lists' q:b_search; the rest works on whole lists at once.
