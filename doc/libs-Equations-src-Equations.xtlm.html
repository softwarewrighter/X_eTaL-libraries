macro librarylibs/Equations/src/Equations.xtlm

Equations: its macro library -- e:e_q<, a sum as printed in a paper. Imported with the functions, under one alias: "e:" u_se< "Equations". A macro is a function from the source text written left and right of its call to the source that replaces the call, run before the program is compiled (X_eTaL MC10). Names with m: are macros; those under h: are private to this file.

ᵐe̲q< : Char -> Char -> Char

macro · line 20

The value of a sum written as a paper prints it. The left names the result, its free indices and their extents; the right lists the sums, outermost first, each an operator word, an index and an inclusive range, then | and the summand, whose brackets index arrays from 0: Y := "Y[o,h,w] | O Ho Wo" e:e_q< "sum c:=0..C - 1, sum r:=0..Kh - 1, sum s:=0..Kw - 1 | X[c,h+r,w+s] * W[o,c,r,s]" Expressions in the strings follow math precedence (* before + and -, left to right). It expands to a grid of every index's values, a gather per array reference and one reduction per sum.

ᵐe̲q< ← { lhs rhs → (ʰf̲ree lhs) ʰl̲ower ʰs̲ums rhs }

Atoms are numbers, the caller's names, indices (replaced) and array references (gathers).
