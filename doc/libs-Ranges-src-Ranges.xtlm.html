Ranges: its macro library -- f_or<, a list of stepped ranges, each bound to a name: "for i:=0..10 by 2". No functions. Imported with the functions, under one alias: "rg:" u_se< "Ranges". A macro is a function from the source text written left and right of its call to the source that replaces the call, run before the program is compiled (X_eTaL MC10). Names with m: are macros; those under h: are private to this file. libs/Parsing/docs/guide.md builds this exact macro step by step, tool by tool, as a worked example of writing a notation macro with libs/Parsing.

The macro

ᵐf̲or< : Unit -> Char -> Char

macro · line 85

for i:=0..10 by 2, for j:=0..len(A)-1: a comma-separated list of stepped ranges, lowest to highest inclusive, each bound to its own name (i and j here). The step (by 2) is optional, 1 when it is not written. A bound is a number, a parenthesized chain of them, an array's length (len(A)) or one of its elements (A[0]). When the program is compiled, each binding becomes a plain array built from r_ange, so nothing about the range is computed again at run time beyond what the program itself asks for. A malformed range, an unknown loop word, a non-whole step, or any text left over once every piece is read, stops the compiler: error[bad-range]. It stands as a statement of its own.

ᵐf̲or< ← { @ text →
  pieces ← '{ p → ʰp̲iece d̲isclose p } m̲ap "," ᵖᵃs̲plit ᵗt̲rim text
  reprint ← "," ᵗj̲oin '{ b → (rp, _) ← d̲isclose b◆ rp } m̲ap pieces
  _ ← "bad-range right" ᵖᵃw̲hole (text, reprint)
  "" ᵗj̲oin '{ b → (_, st) ← d̲isclose b◆ st } m̲ap pieces
}
