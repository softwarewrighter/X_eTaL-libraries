ᵐc̲ases< : Char -> Char -> Char

macro · line 43

"u:s_quare" k:c_ases< "2 -> 4; 3 -> 9; -1 -> 1": a table of checks of one function, a row per case, input -> expected. When the program is compiled it writes one check per row, named by its own source text ("ok: u:s_quare 2", or "FAIL: u:s_quare 3: expected 9, got 10"), so a failing case says which, without writing the expression twice. Expected and actual values must share a type: a mismatch is a type error at compile time. It stands as a statement of its own. A row without one -> stops the compiler: error[bad-cases].
