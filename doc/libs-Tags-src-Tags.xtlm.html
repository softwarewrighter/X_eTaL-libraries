macro librarylibs/Tags/src/Tags.xtlm

Tags: macros only -- e_num< and p_arts<, names for choices and for the parts of a tuple, written when the program is compiled. Imported under one alias: "tg:" u_se< "Tags". A macro is a function from the source text written left and right of its call to the source that replaces the call, run before the program is compiled (X_eTaL MC10). Names with m: are macros; those under h: are private to this file.

macro · line 111

@ tg:p_arts< "State: w m v k": a tuple whose first part is a tag naming its kind, and functions for it, so its parts are used by name: STATE := "State", the tag; u:s_tate (w, m, v, k), the tagged tuple (STATE, w, m, v, k); u:s_tate? s, whether s is tagged State; per part a getter, u:s_tateW s, and a setter, x u:s_etStateW s, giving s with that part x (of the part's type); and i u:s_tateRows s, the items i of every part, when the parts are the columns of a table.
