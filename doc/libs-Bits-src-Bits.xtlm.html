A macro is a function from the source text written left and right of its call to the source that replaces the call, run before the program is compiled (X_eTaL MC10). ᵐf̲ields< : Unit -> Char -> Char

macro · line 43

@ b:f_ields< "flag:1 mode:3 count:12": named fields of a packed whole number, lowest bits first. When the program is compiled it writes, for each field, a getter (u:m_ode x: the field of x) and a setter (v u:s_etMode x: x with the field set to v), their offsets and sizes worked out as plain numbers, so nothing is computed about the layout at run time. A malformed field, or more than 62 bits, stops the compiler: error[bad-fields]. Nothing goes on the left (@).
