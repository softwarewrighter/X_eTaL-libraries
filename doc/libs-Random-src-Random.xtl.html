librarylibs/Random/src/Random.xtl

Random: effectful draws and distributions, plus pure Philox counter sampling and uniform-disk arrays. Import it with an alias of your choice: "r:" u_se< "Random". Put libs/Random/src on XETAL_PATH ("just path"); the reference is libs/Random/docs. Names with l: are exported; those under h: are private to this file.

Legacy draws use r_oll!, so "xetal run --seed N" makes them repeatable. Their ! suffix denotes effect order. Pure counter sampling below uses explicit seed/identity arrays and is independent of those effects.
