librarylibs/Plot/src/Plot.xtl

Plot: text charts -- bars, sparklines, histograms, scatter plots on a character grid -- and line charts as pictures, with axes, labels and several lines in one chart. Import it with an alias of your choice: "p:" u_se< "Plot". Put libs/Plot/src on XETAL_PATH ("just path"); the reference is libs/Plot/docs. Names with l: are exported; those under h: are private to this file.

A text chart is a character matrix: it prints as lines in a terminal, a notebook or the live demo. A picture (l_ine!) is an SVG document shown with []S_HOW: numbered files from the command line, a pane in the browser.
