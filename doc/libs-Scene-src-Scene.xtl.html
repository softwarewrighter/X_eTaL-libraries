librarylibs/Scene/src/Scene.xtl

Scene: validated v1/v2 numeric arrays, closed solids and rigid groups. Import with "sc:" u_se< "Scene". Functions depend on Extrusion, Vector3, Matrix and RayTrace; the macro also uses Parsing and Strings. Separate arrays keep Int IDs out of Float material/transform data.
