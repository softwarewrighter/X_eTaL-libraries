programlibs/Equations/demos/convolution.xtl

Discrete convolution and correlation as the sums they are, on an asymmetric signal and kernel so the two cannot be confused: the kernel slides reversed in a convolution and as written in a correlation (what a CNN layer computes). Each mode, named every time, and what the paper prints. Run with "just demo Equations convolution"; xetal expand shows the sum each call becomes.
