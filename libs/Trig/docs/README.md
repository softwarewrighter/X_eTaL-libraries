# Trig

trigonometric functions not in the base language

```
"tr:" u_se< "Trig"
```

Put each library's `src/` directory on `XETAL_PATH` (`just path`
prints them; see the [README](../../../README.md)); `tr:` is the
recommended alias.

## Functions

| Function | Type | What |
| -------- | ---- | ---- |
| `tr:i_dentity x` | `a -> a` | the value itself |

## Examples

From `../tests/basics.xtl`:

```
      tr:i_dentity 1 2 3
1 2 3
```
