# Vector3

Batched 3D vector math and rigid transforms, in ordinary X_eTaL.
Import with `"v:" u_se< "Vector3"`; put both `libs/Vector3/src` and
`libs/Matrix/src` on `XETAL_PATH` (`just path`).

See the [reference](docs/README.md), [pivot demo](demos/pivot.xtl)
and [tests](tests/basics.xtl). Run `just demo Vector3` or
`just test-lib Vector3`.
